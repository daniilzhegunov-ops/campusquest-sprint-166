# Стартовый экран и список станций

## Зачем нужна
Стартовый экран помогает новичку понять, как играть, а список станций показывает доступные задания и текущий прогресс.

## Пользовательский сценарий
1. Игрок открывает CampusQuest и видит приветственный экран с краткой инструкцией.
2. Игрок нажимает «Начать квест» и попадает на список станций.
3. В списке станций отображаются названия, статус (доступна / пройдена) и кнопка перехода к заданию.

## Критерий готовности
- На стартовом экране есть заголовок, описание и кнопка «Начать».
- Список станций показывает минимум 3 станции с названиями и статусами.

## Риск или вопрос
- Как должен выглядеть список станций, если все задания уже пройдены?
