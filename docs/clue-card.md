# Карточка загадки

## Зачем нужна
Карточка загадки — основной элемент взаимодействия: игрок читает условие, видит подсказку и поле для ответа.

## Пользовательский сценарий
1. Игрок выбирает станцию и открывает карточку загадки.
2. На карточке отображаются текст задания, иллюстрация (если есть) и подсказка, скрытая под спойлером.
3. Игрок вводит ответ в специальное поле и нажимает «Проверить».

## Критерий готовности
- Карточка содержит текст задания и подсказку (скрытую по умолчанию).
- Есть поле ввода ответа и кнопка «Проверить».
- После нажатия кнопки ответ отправляется на проверку (в рамках прототипа — сравнение с эталоном).

## Риск или вопрос
- Нужна ли возможность вернуться к предыдущей станции без потери прогресса?
