# Проверка ответа

## Зачем нужна
Проверка ответа даёт игроку обратную связь: правильный ответ приносит баллы, неправильный — позволяет попробовать снова или показывает подсказку.

## Пользовательский сценарий
1. Игрок вводит ответ и нажимает «Проверить».
2. Система сравнивает ответ с эталоном (без учёта регистра и лишних пробелов).
3. Если ответ верный — игрок видит сообщение «Верно!» и получает баллы; если нет — сообщение «Попробуйте ещё раз» и возможность исправить.

## Критерий готовности
- Правильный ответ распознаётся и начисляет баллы.
- Неправильный ответ не блокирует повторную попытку.
- Сообщение об ошибке не раскрывает правильный ответ сразу.
